Tentang

Latar belakang dan keahlian teknis

Pengalaman langsung di jaringan, administrasi server Linux, dan monitoring infrastruktur, lewat peran sebagai research intern, asisten praktikum, mentor, dan kepala sub-divisi infrastruktur.

Saya masuk ke dunia jaringan lewat Adaptive Network Laboratory. Awalnya cuma merancang topologi dan mengurus subnetting, lalu pelan-pelan meluas ke administrasi server Linux, virtualisasi, dan hosting. Sekarang saya memimpin sub-divisi yang bertanggung jawab atas jaringan, server, dan layanan hosting laboratorium.

Di Telkom Test House pekerjaannya lebih spesifik. Saya mendiagnosis server yang gagal booting sampai ketemu akar masalahnya di motherboard, mengimplementasikan protokol TR-369/USP pada perangkat akses GPON, dan membangun monitoring telemetri perangkat jaringan secara real time.

Bagian yang paling saya nikmati justru perawatannya. Menyiapkan dashboard, mengatur alert, dan menulis automasi supaya pekerjaan berulang tidak perlu dikerjakan manual tiap minggu.

Fokus saya sekarang ada di network engineering, administrasi server Linux, dan monitoring infrastruktur.
